# NPMC Launcher 1.0.0-beta.2（预发布）

第二个公开测试版。Windows x64 单文件，自带 .NET 运行时，**不需要安装任何前置**
（不需要装 .NET、不需要 Java —— 游戏运行时由启动器自动下载）。

> 这是预发布版本：功能已基本跑通，但仍可能有未覆盖的边界情况，遇到问题请带上 `logs/` 目录反馈。

## 相对 beta.1 的变化

### 模组更新检查（重点修正）

- **「检查更新」只查该查的**：以前文案写"已跳过 99 个整合包自带模组"，实际把 100 个全查了一遍，
  还按全部结果报"29 个可升级"。现在严格按列表状态决定范围。
- **展开整合包模组时才检查它们**：默认隐藏整合包自带模组、只查手动添加的；
  取消勾选（展开查看）后才会把整合包自带的也一起检查。
- **按整合包平台优先查询**：CurseForge 包自带的模组只走 CurseForge；
  Modrinth 包走 Modrinth 优先；MultiMC 包（没有上游平台）两边都查。
  **用户自己添加的模组不套用这个偏好**，始终两个平台都查。
- **「全部升级」与检查范围一致**：只升上次实际检查过的文件，不再出现"收起列表后把残留的更新也升掉"。
- **全部升级加二次确认**：第一次点只显示"将升级 N 个（其中 M 个是整合包自带，升级后可能偏离作者的版本组合）"，
  再点一次才执行；8 秒不动自动取消。

### 模组来源徽标

- **MultiMC 实例包不再把所有模组标成 Modrinth**：以前清单里的每个文件都被预打"M"，
  连从未上传的模组也一样。现在 MultiMC 包交给哈希识别，认不出来就显示 `?`。
- 实例徽标改为「**MultiMC 实例包（其它启动器导出）**」，不再和平台整合包混称。

### 整合包导出

- 「完整 ZIP」替换为 **MultiMC 实例包**：`.minecraft/` + `mmc-pack.json`（游戏版本 + 加载器）
  + `instance.cfg`（名字 / 内存 / 窗口）。导出后可以再导入，形成闭环。
- 新增「包含存档（saves/）」勾选，默认不带（存档属于个人数据）。
- 导出/导入页都加了 **❓** 悬停说明：包是怎么生成的、包含什么、导入时怎么处理、来源是什么。

### 翻译

- **长简介不再只翻前半段**：正文切成 ≤900 字的小段分别翻译再拼接；
  只有整段成功才写缓存，半截结果会标注「…（后文未翻译）」且不落盘。
- **新增 Bing（微软）翻译端点**（不需要 API key），回退链为
  gtx → Bing → dict-chrome-ex → MyMemory，各自 10 分钟冷却。
- **改成按需翻译**：打开详情只查缓存，没命中时显示「机翻这段简介」按钮，点一下才请求；
  另有每小时 120 次的本地配额，避免把 IP 打黑。
- 译文缓存改为可维护的 `translations.csv`（UTF-8 BOM，Excel 可直接编辑）+ 纯元数据 `meta.json`。

### 缓存与磁盘

- 设置页新增「缓存」区块：显示各目录占用与可清理量，一键清理可再生的缓存
  （图标 / 整合包解压产物 / Forge 安装包 / 安装器临时目录），译文表与皮肤不动。
- 启动时自动清理超过 3 天的安装器临时残留。
- 图标缓存从"每图标一个文件"压成 `icons.pack` + `icons.idx.json`（LRU：600 条 / 32 MB）。
- Forge / NeoForge 安装不再往游戏根目录堆 `.jar.log`：成功即删，失败归档到 `logs/loader-install/`。

### 界面

- 实例内存框修复：切换实例后不再显示空白（漏了变更通知）。
- 导出页与导航栏精简：语法说明收进悬停，删掉重复的导航提示。
- 导出/导入的说明不再列举其它启动器的名字。

## 环境要求

| 项目 | 要求 |
| --- | --- |
| 系统 | Windows 10 1607+ / Windows 11，**x64** |
| 运行时 | 无需安装（exe 自带 .NET 8 运行时，不依赖 VC++ 运行库） |
| 位置 | 放在**可写目录**（会在 exe 旁创建 `data/`、`minecraft/`、`runtime/`） |
| 网络 | 首次安装游戏/Java 需要联网 |

放 `Program Files` 会因权限失败；`%TEMP%` 被策略禁用时会启动不了（单文件需要解压原生库）。

## 已知限制

- **联机（P2P）入口目前置灰**，代码保留但不开放。
- 未做代码签名：别的机器首次运行会提示"未知发布者"。
- 公共翻译端点按 IP 限流，额度不公开；触发限流时只会显示原文或缓存译文。
- 搜索标签分类仍偏宽（Modrinth 的 `technology` 标签），暂未细分。

## 快速开始

1. 双击 `NPMC.Launcher.App.exe`；
2. 「下载」页选择游戏版本 → 点「下载并创建实例」（首次会自动下载本体与 Java 运行时）；
3. 想装整合包：下载页切到「整合包」，在线搜索或把 `.mrpack` / `.zip` 拖进页面；
4. 启动失败时看「日志」页或实例概览里的诊断卡片，`logs/launches/<时间>/` 里有完整归档。

## 校验

发布页附带 `SHA256SUMS.txt` 与 `NPMC.Launcher.App.exe.sha256`，与 exe 同名同目录即可校验：

```powershell
Get-FileHash .\NPMC.Launcher.App.exe -Algorithm SHA256
```
